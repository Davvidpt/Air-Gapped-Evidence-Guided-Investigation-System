# Local runtime data (NOT for git)

- `incoming/`: ZIP selected by operator, quarantine/staging.
- `archive/`: preserved original ZIP copy with receipt metadata.
- `processed/`: non-sensitive derived outputs where needed.
- `aegis.db`: SQLite created locally by prototype importer.

Do not publish real endpoint artifacts, device IDs, usernames, paths, hashes linked to private systems, or reports containing them.
